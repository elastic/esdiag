# esdiag-core

Core library of [ESDiag](https://github.com/elastic/esdiag), the Elastic Stack diagnostic collector and processor: collection, processing, export, setup assets, and configuration.

This is an implementation crate of [`esdiag`](https://crates.io/crates/esdiag), published in lockstep with it so that `cargo install esdiag` builds from crates.io. It has no supported public API, and any release may change it without notice. Install the tool with:

```sh
cargo install esdiag
```
