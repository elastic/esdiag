# Elastic Stack Diagnostics Additional Executables

1. [`esdiag-control`](../docs/bin/esdiag-control.md) - Setup, build or run Elastic Stack Diagnostics
2. [`esdiag-lite.sh`](../docs/bin/esdiag-lite.md) and [`esdiag-lite.ps1`](../docs/bin/esdiag-lite.md) - Version-aware, minimal-dependency Elasticsearch diagnostic collection for Bash and Windows PowerShell
3. `elastic-diag` - Elastic CLI extension entrypoint that delegates to `esdiag`
